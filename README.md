### 🚀 Proyectos Destacados

*   🌱 **Sistema de Monitoreo Ambiental (Pecera Inteligente):** Arquitectura IoT desarrollada con ESP32, sensores (DS18B20, HC-SR04, LDR) y RTC DS1307, transmitiendo en tiempo real vía MQTT hacia un servidor Node.js/MongoDB, con interfaz móvil en React Native.
*   📊 **Plataforma de Registro de Datos (Datalogger):** Sistema interactivo de recolección basado en ESP32 V1. Cuenta con interfaz local mediante pantalla LCD I2C y módulo touch, además de retroalimentación mediante LED RGB y buzzer activo. Garantiza el sellado de tiempo exacto con un RTC DS1307 y almacena los registros de forma estructurada en un módulo MicroSD.
